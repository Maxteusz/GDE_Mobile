# About App
The application is intended for warehouse collectors, and its main task is to streamline warehouse management in the process of issuing, receiving, and inventorying goods.
<br>It is integrated with the Enova 365 system, and data regarding goods, contractors, resources, or documents are retrieved from the database via an API. An additional convenience is the ability to scan goods using the built-in camera of a mobile phone, so if a warehouse collector is not at hand, a regular phone can be used.
